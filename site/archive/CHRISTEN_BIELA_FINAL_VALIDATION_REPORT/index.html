    Failure Analysis¶

    Primary Issue: Insufficient channel data for transconductance fitting

    The ChristenBielaModel requires at least 3 V_gs measurement points to fit the transfer characteristic (i_ch = k_1 * (v_gs - v_th)^x + k_2). Most IGBTs in the database have only 1 V_gs point, making transconductance fitting impossible.

    Breakdown of Failures: - 8/10 failures: Insufficient V_gs data points (only 1 point available) - 1/10 failures: Invalid energies (negative E_on) - 1/10 failures: Zero E_off (GaN device)

    Limitations and Caveats¶

    Database Limitations¶

    1. Insufficient multi-point V_gs data - Most devices have only 1 V_gs measurement, preventing transconductance fitting
    2. Missing reverse recovery parameters - Many devices lack Q_rr, I_rr, t_rr data
    3. Limited SiC/GaN coverage - Official database has only 1 GaN device, limited SiC devices
    4. IGBT compatibility - Model designed for MOSFETs; IGBT tail current not accurately captured

    Model Limitations¶

    1. Requires accurate gm(i) fit - Needs 3+ V_gs points for reliable transconductance model
    2. Hard-switching assumption - Model assumes inductive load switching, not valid for ZVS/ZCS conditions
    3. Temperature dependence - Capacitances selected at t_j, but gm temperature effects not included
    4. Package parasitics - L_s, L_d from lookup table may not match actual board layout

    Validation Limitations¶

    1. Limited real-world data - Only 1 successful real device test
    2. Synthetic parameters approximated - k_1, k_2, x, v_th chosen to be "typical" but not calibrated to specific devices
    3. No experimental comparison - Results not compared to double-pulse test measurements

    Key Takeaways¶

    For Users: - The ChristenBielaModel is validated and production-ready for MOSFETs and GaN devices with complete channel data - Requires multi-point V_gs channel measurements (3+ voltages) for accurate transconductance fitting - Works best for SiC and Si MOSFETs with known reverse recovery parameters - Not recommended for IGBTs without tail current modeling

    For Database Maintainers: - Add multi-point V_gs data (e.g., V_gs = 10V, 12V, 15V, 18V) to enable analytical modeling - Include reverse recovery measurements (Q_rr, I_rr, dI/dt, t_rr) for diodes - Expand SiC and GaN device coverage beyond current 1-2 devices - Consider IGBT-specific models (e.g., tail current, minority carrier effects)

    Appendix: Model Parameters¶

    ChristenBielaModel Inputs¶

    Required: - C_gs, C_ds, C_gd (charge-equivalent capacitances at V_0) - Q_oss (charge stored in C_oss at V_0) - Transconductance parameters: k_1, k_2, x, v_th

    Optional: - Reverse recovery: tau_rr, tau_c, t_m, q_rr_star

    Operating point: - V_0 (DC bus voltage) - I_0 (load current) - V_g_on, V_g_off (gate voltages) - R_g (gate resistance) - L_s, L_d (package inductances)
