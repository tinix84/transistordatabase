    Methods Implemented¶

    1. __init__: Store device parameters (capacitances, Q_oss, gm_params, rr_params)

    2. _solve_i_oss: Iterative quadratic solver implementing eq(10)

    3. Solves for C_oss charging current I_oss
    4. Iterates until transconductance g_m converges (<1%)
    5. Handles ZVS condition (no real solution)

    6. Returns (i_oss, gm, v_mil)

    7. calc_turn_off_energy: Turn-off energy calculation

    8. Interval 0a: Gate voltage drop (lossless, not calculated)
    9. Interval 1a: Voltage rise (eq 10, eq 13)
      • Solve for I_oss
      • Calculate t_rv = Q_oss / I_oss
    10. Interval 2a: Current fall (CORRECTED eq 15, eq 16)
      • Calculate t_fi with corrected equation
      • Calculate V_Ld overvoltage
    11. Energy: eq(17) E_T,off = E_1a + E_2a

    12. Returns dict with e_off, i_oss, v_mil, t_rv, t_fi, v_ld, gm

    13. calc_i_0_zvs: ZVS boundary current (eq 14)

    14. Maximum current for lossless turn-off
    15. Returns 0 if no ZVS possible (discriminant < 0)

    Usage Example¶

    from transistordatabase.analytical_models import (
    ChristenBielaModel,
    HalfBridgeParams,
    TransconductanceParams,
)

# Device parameters
gm_params = TransconductanceParams(k_1=0.4, k_2=0.0, x=1.8, v_th=3.5)
model = ChristenBielaModel(
    c_gs=2.5e-9, c_ds=0.5e-9, c_gd=0.3e-9, q_oss=100e-9,
    gm_params=gm_params, rr_params=None
)

# Operating conditions
params = HalfBridgeParams(
    v_0=600.0, i_0=20.0, v_g_on=20.0, v_g_off=-5.0,
    r_g=10.0, l_s=5e-9, l_d=10e-9
)

# Calculate turn-off energy
result = model.calc_turn_off_energy(params)
print(f"E_T,off = {result['e_off']*1e6:.2f} µJ")

# ZVS boundary
i_0_zvs = model.calc_i_0_zvs(params)
print(f"I_0,zvs = {i_0_zvs:.2f} A")

    Key Implementation Features¶

    1. Iterative Convergence
    2. Transconductance g_m depends on channel current I_ch = I_0 - 2*I_oss
    3. Solver iterates: g_m(I_0) → solve I_oss → g_m(I_0 - 2*I_oss) → ...

    4. Converges in 2-4 iterations (1% tolerance)

    5. Errata Corrections Applied

    6. eq(10): Positive leading coefficient (supplement confirms)

    7. eq(15): Corrected sign (V_th - V_g) / (V_mil - V_g) where V_g = V_g,off

    8. Physical Constraints

    9. Zero current → zero energy
    10. I_oss ≥ 0 (capacitor charging current)
    11. I_0 < 2*I_oss → ZVS (E_off ≈ 0)

    12. Energy increases with voltage and current

    13. Robust Edge Cases

    14. Handles I_0 = 0 (returns 0 energy)
    15. Handles ZVS condition (discriminant < 0)
    16. Handles near-threshold operation (minimal gm)
    17. Guards against division by zero
