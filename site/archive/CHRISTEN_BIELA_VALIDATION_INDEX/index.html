    How to Use¶

    For Users¶

    1. Understand the validation:

    2. Read CHRISTEN_BIELA_FINAL_VALIDATION_REPORT.md

    3. Use the model: 

      from transistordatabase.analytical_models import ChristenBielaModel
from transistordatabase.core.repository import JsonTransistorLoader

# Load device
loader = JsonTransistorLoader()
transistor = loader.load_from_json("path/to/device.json")

# Create model
model = ChristenBielaModel.from_transistor(
    transistor, v_0=800.0, t_j=25.0
)

# Calculate switching energy
result = model.calc_switching_energy(params)

    4. Check device compatibility:

    5. Requires 3+ V_gs channel measurements
    6. Works best with SiC, Si MOSFETs, GaN
    7. Not recommended for IGBTs without tail current data

    For Database Maintainers¶

    1. Review the validation:
    2. See failure analysis in test log

    3. Understand why 91% of tests failed

    4. Improve database:

    5. Add multi-point V_gs data (3-5 gate voltages)
    6. Include reverse recovery parameters (Q_rr, I_rr, t_rr)

    7. Expand SiC and GaN device coverage

    8. Re-run validation: 

      python3 validate_christen_biela.py

    For Developers¶

    1. Study the model:
    2. Read transistordatabase/analytical_models.py

    3. Review Christen-Biela paper (DOI: 10.1109/TPEL.2018.2851068)

    4. Run validation scripts: 

      # Test real database
python3 validate_christen_biela.py

# Test synthetic devices
python3 validate_christen_biela_extended.py

    5. Extend validation:

    6. Add more synthetic test cases
    7. Compare with experimental DPT data
    8. Test edge cases (ZVS, high R_g, etc.)
