================================================================================
NTBEE2 INTEGRATION - QUICK START GUIDE
================================================================================

OVERVIEW
--------
ntbee2 (Neural Twin Bee) is a power electronics loss calculation framework
that uses CSV-based semiconductor databases compatible with TDB (Transistor
Database) via bidirectional converters.

Two CSV formats supported:
1. plecs_devices.csv (14 columns) - Single test point measurements
2. raggl_combos.csv (23 columns) - Transistor+diode combos with Raggl coefficients

================================================================================
CSV SCHEMAS AT A GLANCE
================================================================================

PLECS DEVICES (plecs_devices.csv)
---------------------------------
14 Columns | Loader: SemiconductorRecord | Purpose: Loss calculations

Required Fields (10):
  part_number, vendor, type, technology, V_br_V, E_on_uJ, E_off_uJ, 
  V_test_V, I_test_A, Rth_jc_KW

Optional Fields (4):
  R_dson_mOhm, V_ce_sat_V, R_d_mOhm, package

Example Row:
  C2M0080120D,Wolfspeed,mosfet,SiC,650,80,,,150,120,400,20,0.5,TO-247

RAGGL COMBOS (raggl_combos.csv)
-------------------------------
23 Columns | Loader: DeviceComboRecord | Purpose: PFC loss calculations

Required Fields (21):
  combo_id, transistor_pn, diode_pn, vendor, technology, V_class_V, V_test_V,
  R_dson_mOhm, a_on_uJ, k_on_uJ_A, a_off_uJ, k_off_uJ_A2, a_RR_uJ, k_RR_uJ_A,
  U_f_V, R_f_mOhm, Rth_jc_trans_KW, Rth_jc_diode_KW, n_Eon_points, r2_Eon, r2_Eoff

Optional Fields (2):
  V_ce_sat_V, package

Raggl Model:
  E_on(I)  = a_on  + k_on  × I          [µJ, linear]
  E_off(I) = a_off + k_off × I²         [µJ, quadratic]
  E_RR(I)  = a_RR  + k_RR  × I          [µJ, linear]

================================================================================
TDB ↔ NTBEE2 FIELD MAPPING
================================================================================

TDB (Input) → ntbee2 (Output)
-----------------------------
metadata.name                     → part_number / transistor_pn / combo_id
metadata.type                     → type (mosfet | igbt | diode)
metadata.manufacturer             → vendor
electrical_ratings.v_abs_max      → V_br_V
switch.channel_data[].r_channel   → R_dson_mOhm (×1000 conversion)
switch.e_on_data[].energy         → E_on_uJ (×1e6 conversion)
switch.e_off_data[].energy        → E_off_uJ (×1e6 conversion)
thermal_properties.r_th_jc        → Rth_jc_KW
metadata.housing                  → package

ntbee2 (Input) → TDB (Output)
-----------------------------
part_number                       → metadata.name
type                              → metadata.type
vendor                            → metadata.manufacturer
V_br_V                            → electrical_ratings.v_abs_max
R_dson_mOhm                       → switch.channel_data[0].r_channel (÷1000)
E_on_uJ                           → switch.e_on_data[0].energy (÷1e6)
E_off_uJ                          → switch.e_off_data[0].energy (÷1e6)
Rth_jc_KW                         → thermal_properties.r_th_jc

================================================================================
CONVERTER USAGE
================================================================================

Installation:
  python tdb_to_ntbee2_converter.py ./tdb_jsons ./plecs_devices.csv

Basic Usage - TDB → plecs_devices.csv:
  python tdb_to_ntbee2_converter.py /path/to/tdb/jsons output.csv

Raggl Format - TDB → raggl_combos.csv (synthesized):
  python tdb_to_ntbee2_converter.py /path/to/tdb/jsons output.csv --raggl

With Parameters:
  python tdb_to_ntbee2_converter.py /path/to/tdb/jsons output.csv \
    --raggl --tech SiC --vclass 650

Parameters:
  --raggl              : Use Raggl format (default: plecs)
  --tech {Si|SiC|GaN}  : Override technology (default: SiC)
  --vclass {600|900|1200|1700} : Voltage class for Raggl (default: 600)

Output:
  ✓ Converted N transistors to output.csv
  ⚠ WARNING: Raggl coefficients are synthesized from single test points

================================================================================
UNIT CONVERSIONS
================================================================================

TDB → ntbee2:
  Resistance:  [Ω] × 1000 = [mΩ]              (e.g., 0.1 Ω → 100 mΩ)
  Energy:      [J] × 1e6  = [µJ]              (e.g., 1e-4 J → 100 µJ)
  Thermal R:   [K/W] = [K/W]                  (direct, same units)
  Voltage:     [V] = [V]                      (direct, same units)
  Current:     [A] = [A]                      (direct, same units)

ntbee2 → TDB:
  Resistance:  [mΩ] ÷ 1000 = [Ω]              (e.g., 100 mΩ → 0.1 Ω)
  Energy:      [µJ] ÷ 1e6  = [J]              (e.g., 100 µJ → 1e-4 J)

================================================================================
DATA QUALITY CHECKLIST
================================================================================

Before Exporting to ntbee2:
  ☐ All required fields are populated (not NaN/empty)
  ☐ Voltage class matches breakdown voltage (V_br_V)
  ☐ Technology matches device type (SiC for SiC MOSFETs)
  ☐ Switching energies > 0 (E_on_uJ, E_off_uJ)
  ☐ Thermal resistance > 0 (Rth_jc_KW)
  ☐ Part numbers are unique (no duplicates)
  ☐ Package field uses standard designations
  ☐ Raggl fit quality is acceptable (r2_Eon, r2_Eoff > 0.8)

Fallback Values (if missing):
  R_ds_on:          100 mΩ
  R_th_jc:          0.5 K/W (MOSFET), 1.0 K/W (IGBT)
  U_f (diode):      0.7 V
  R_f (diode):      10 mΩ
  V_class:          600 V (standard for SiC 650V)

================================================================================
ACCURACY & LIMITATIONS
================================================================================

plecs_devices.csv Format:
  • Accuracy: 85-90%
  • Single test point with voltage/current linear scaling
  • No temperature-dependent curves
  • Good for quick FOM ranking, efficiency maps

raggl_combos.csv Format (Synthesized from TDB):
  • Accuracy: 60-70%
  • Heuristic split: a=0.3×E_test, k=0.7×E_test/I_test
  • Low R² fit (0.5) indicates single-point derivation
  • Assumes PFC sinusoidal current profile
  • NOT recommended for high-accuracy simulations

TDB Native Format:
  • Accuracy: 95-98%
  • Full measurement curve data
  • Temperature-dependent models
  • Arbitrary topology support
  • Best for detailed analysis

================================================================================
COMMON ISSUES & SOLUTIONS
================================================================================

Issue: Missing channel_data in TDB
  Solution: Use fallback R_ds_on = 100 mΩ (converter default)

Issue: E_on/E_off at different (V, I) than standard test point (400V, 20A)
  Solution: Linear scaling: E_target = E_measured × (V_target/V_measured) × (I_target/I_measured)

Issue: No thermal data in TDB
  Solution: Use technology defaults:
    - SiC MOSFET: 0.5-1.0 K/W
    - Si MOSFET: 0.5-2.0 K/W
    - IGBT: 0.3-1.5 K/W

Issue: Raggl model R² < 0.8
  Solution: Flag as low-quality; use plecs format instead for better fidelity

Issue: Empty diode part number
  Solution: Auto-generate as "{transistor_pn}-diode" (converter default)

LOSS CALCULATION EXAMPLES
================================================================================

Using ntbee2 plecs_devices.csv:
  
  from models.semiconductor_database import (
    load_semiconductor_database, 
    record_to_device_model
  )
  
  db = load_semiconductor_database()
  records = db  # List of SemiconductorRecord
  
  # Convert to polynomial model
  device = record_to_device_model(records[0])
  
  # Calculate losses at operating point
  P_cond = device.P_cond(I_rms=10.0, V_rating=400.0)   # Conduction loss [W]
  P_sw = device.P_sw(V_sw=400.0, I_sw=20.0, f_sw=100e3) # Switching loss [W]
  P_total = device.P_total(I_rms=10.0, V_sw=400.0, I_sw=20.0, f_sw=100e3)
  
  # Temperature-dependent
  P_cond_tj = device.P_cond_at_Tj(I_rms=10.0, T_j=125.0, V_rating=400.0)

Using ntbee2 raggl_combos.csv:

  from models.semiconductor_combo_database import (
    load_combo_database,
    raggl_P_sem
  )
  
  db = load_combo_database()
  combos = db  # List of DeviceComboRecord
  
  # Calculate losses for PFC at 10kHz, 400V DC bus
  result = raggl_P_sem(
    combo=combos[0],
    I_rms=10.0,          # Phase RMS current [A]
    I_peak=14.14,        # Phase peak current [A]
    f_sw=10e3,           # Switching frequency [Hz]
    V_dc=400.0,          # DC bus voltage [V]
    n_switches=6,        # 3-phase bridge
    is_clamped=False
  )
  
  P_sem = result['P_semiconductor_W']
  P_per_chip = result['P_per_chip_W']
  P_cond = result['P_conduction_W']
  P_sw = result['P_switching_W']

Key Questions:
  Q: Which format should I use?
  A: Use plecs_devices.csv unless you need Raggl PFC-specific features

  Q: How accurate is the conversion?
  A: ~85-90% for plecs, ~60-70% for synthesized Raggl (use TDB for 95%+)

  Q: Can I use ntbee2 CSV in TDB directly?
  A: Yes, via reverse converter (not yet implemented - Phase 2)

  Q: Are temperature-dependent losses supported?
  A: DeviceModel has alpha_T/beta_T; Semiconductor model uses curves
