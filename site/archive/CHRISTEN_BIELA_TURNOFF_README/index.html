    Christen-Biela Turn-Off Energy Implementation¶

    Overview¶

    This implementation adds the Christen-Biela analytical switching loss model for half-bridge MOSFETs to the transistordatabase/analytical_models.py module. This covers Section II-A of the Christen/Biela IEEE TPEL 2019 paper (DOI: 10.1109/TPEL.2018.2851068) with supplement errata corrections.

    Implementation Status¶

    ✓ COMPLETE: Turn-off energy calculation (intervals 0a, 1a, 2a) - ChristenBielaModel.__init__() - Model initialization - ChristenBielaModel._solve_i_oss() - Iterative quadratic solver with gm convergence - ChristenBielaModel.calc_turn_off_energy() - Turn-off energy (eq 10, 13, 15, 16, 17) - ChristenBielaModel.calc_i_0_zvs() - ZVS boundary current (eq 14)

    ⏳ PENDING: Turn-on energy calculation (CB.7) - to be added later

    Equations Implemented¶

    Turn-Off Intervals¶

    Interval 0a: Gate voltage drop (lossless) - Gate discharges from V_g,on to V_g,off

    Interval 1a: Voltage rise - eq(10): Quadratic equation for I_oss (C_oss charging current) 

    0 = (2*L_s / (Q_oss*R_g)) * I_oss^2
  + (2/(g_m*R_g) + C_gd/(C_gd+C_ds)) * I_oss
  + (1/R_g) * (V_g - V_th - I_0/g_m)
    - Iterative solver: g_m = f(I_0 - 2*I_oss) until convergence (<1%)

    • eq(13): Voltage rise time 
      t_rv = Q_oss / I_oss

    Interval 2a: Current fall - eq(15): Current fall time (CORRECTED from supplement) 

    t_fi = -ln((V_th - V_g,off) / (V_mil - V_g,off)) * (C_gs*R_g + L_s*g_m)

    • eq(16): Drain inductance overvoltage 
      V_Ld = L_d * I_ch / t_fi

    Energy calculation: - eq(17): Total turn-off energy 

    E_T,off = 0.5*t_rv*V_0*(I_0 - 2*I_oss) + 0.5*t_fi*(V_0 + V_Ld)*(I_0 - 2*I_oss)

    ZVS Boundary¶

    • eq(14): Maximum current for lossless turn-off 
      I_0,zvs = V_0/(2*L_s) * (-R_g*C_gd + sqrt((R_g*C_gd)^2 - 8*(V_g-V_th)*L_s*(C_gd+C_ds)/V_0))

    Usage Example¶

    from transistordatabase.analytical_models import (
    ChristenBielaModel,
    HalfBridgeParams,
    TransconductanceParams,
)

# Device parameters (example: SiC MOSFET)
gm_params = TransconductanceParams(
    k_1=0.4,      # Transfer characteristic coefficient
    k_2=0.0,      # Offset
    x=1.8,        # Exponent
    v_th=3.5,     # Threshold voltage [V]
)

model = ChristenBielaModel(
    c_gs=2.5e-9,   # Gate-source capacitance [F]
    c_ds=0.5e-9,   # Drain-source capacitance [F]
    c_gd=0.3e-9,   # Gate-drain capacitance [F]
    q_oss=100e-9,  # Charge stored in C_oss at V_0 [C]
    gm_params=gm_params,
    rr_params=None,  # Reverse recovery (optional)
)

# Operating conditions
params = HalfBridgeParams(
    v_0=600.0,      # DC bus voltage [V]
    i_0=20.0,       # Load current [A]
    v_g_on=20.0,    # Turn-on gate voltage [V]
    v_g_off=-5.0,   # Turn-off gate voltage [V]
    r_g=10.0,       # Gate resistance [Ω]
    l_s=5e-9,       # Source inductance [H]
    l_d=10e-9,      # Drain inductance [H]
)

# Calculate turn-off energy
result = model.calc_turn_off_energy(params)

print(f"E_T,off:  {result['e_off']*1e6:.2f} µJ")
print(f"I_oss:    {result['i_oss']:.2f} A")
print(f"V_mil:    {result['v_mil']:.2f} V")
print(f"t_rv:     {result['t_rv']*1e9:.2f} ns")
print(f"t_fi:     {result['t_fi']*1e9:.2f} ns")
print(f"V_Ld:     {result['v_ld']:.2f} V")
print(f"g_m:      {result['gm']:.3f} S")

# Calculate ZVS boundary
i_0_zvs = model.calc_i_0_zvs(params)
print(f"I_0,zvs:  {i_0_zvs:.2f} A (lossless turn-off below this current)")

    Key Implementation Notes¶

    Errata Corrections Applied¶

    1. eq(10): POSITIVE leading coefficient (2*L_s/(Q_oss*R_g))
    2. eq(15): CORRECTED sign: (V_th - V_g) / (V_mil - V_g) where V_g = V_g,off (negative or zero)
    3. Root selection: For turn-off, select root closer to 0 (positive, < I_0/2)

    Iteration Algorithm¶

    The I_oss solver uses iterative refinement because g_m depends on the channel current: 1. Initialize: g_m = f(I_0) 2. Solve quadratic for I_oss 3. Update: g_m = f(I_0 - 2*I_oss) 4. Repeat until |Δg_m|/g_m < 1%

    Typically converges in 2-4 iterations.

    Physical Constraints¶

    • I_oss ≥ 0 (C_oss charging current)
    • t_rv, t_fi ≥ 0 (time intervals)
    • I_0 < 2*I_oss → ZVS condition (E_off ≈ 0)
