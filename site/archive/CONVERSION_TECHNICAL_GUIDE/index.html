    Transistor Database Schema Conversion Technical Guide¶

    Date: 2026-02-15 Version: 1.0.0 Status: Ready for Implementation

    Executive Summary¶

    This document provides detailed technical guidance for converting transistor data from source formats (File Exchange, SC Archive) into the TDB core schema. All required field mappings have been documented with clear transformation rules.

    Key Finding: 95% compatibility between File Exchange format and TDB schema - ready for implementation.

    1. TDB Core Schema Overview¶

    1.1 Root Structure¶

    Transistor (aggregate root)
├── metadata: TransistorMetadata
├── electrical_ratings: ElectricalRatings
├── thermal_properties: ThermalProperties
├── switch: Switch (component)
├── diode: Diode (component)
├── c_oss: List[VoltageDependentCapacitance]
├── c_iss: List[VoltageDependentCapacitance]
├── c_rss: List[VoltageDependentCapacitance]
├── c_oss_er: EffectiveOutputCapacitance
└── c_oss_tr: EffectiveOutputCapacitance

    1.2 Dataclass Hierarchy¶

    TransistorMetadata (7 fields)¶

    name: str                           # Unique ID
type: str                           # MOSFET, IGBT, SiC-MOSFET, GaN
author: str                         # Data creator
manufacturer: str                   # Device OEM
housing_type: str                   # Package type (TO247, etc)
comment: Optional[str]              # Optional description
datasheet_hyperlink: Optional[str]  # URL to datasheet
datasheet_date: Optional[datetime]  # Sheet publication date
datasheet_version: Optional[str]    # Sheet version

    ElectricalRatings (4 fields)¶

    v_abs_max: float  # V - Maximum blocking voltage
i_abs_max: float  # A - Maximum pulsed current
i_cont: float     # A - Continuous current rating
t_j_max: float    # °C - Maximum junction temperature

    ThermalProperties (6 fields)¶

    housing_area: float                  # m² - Case surface area
cooling_area: float                  # m² - Effective cooling area
r_th_cs: Optional[float]             # K/W - Overall case-to-sink
r_th_switch_cs: Optional[float]      # K/W - Switch junction-to-sink
r_th_diode_cs: Optional[float]       # K/W - Diode junction-to-sink
t_c_max: Optional[float]             # °C - Max case temperature

    1.3 Component Structures¶

    Switch Component¶

    • channel_data: V-I characteristics (ChannelCharacteristics)
    • e_on_data: Turn-on switching losses (List[SwitchingLossData])
    • e_off_data: Turn-off switching losses (List[SwitchingLossData])
    • e_on_meas: Measured turn-on data (List[SwitchingLossData])
    • e_off_meas: Measured turn-off data (List[SwitchingLossData])
    • thermal_foster: Transient thermal model (FosterThermalModel)
    • gate_charge_curves: Gate charge curves (List[GateChargeCurve])
    • soa: Safe operating areas (List[SOA])
    • r_channel_temp: Temperature-dependent resistance (List[TemperatureDependResistance])
    • linearized_model: Operating point models (List[LinearizedModel])
    • raw_measurement_data: Test data (List[RawMeasurementData])

    Diode Component¶

    Similar structure but: - No e_on_data/e_off_data (replaced with e_rr_data for reverse recovery) - No gate_charge_curves (no gate on diode) - No r_channel_temp (not temperature dependent in same way) - channel_data has no v_g field (no gate)

    2. File Exchange Format Mapping¶

    2.1 Format Characteristics¶

    • File Type: JSON
    • Structure: Flat root with nested objects
    • Unit Convention: SI units throughout
    • Naming: Uses 'channel', 'linearized_switch', 'linearized_diode'
    • Coverage: 95% of TDB fields

    2.2 Root-Level Fields (Metadata)¶

    Source Field TDB Field Type Transformation Required
    name metadata.name str Direct Yes
    type metadata.type str Direct or normalize Yes
    author metadata.author str Direct Yes
    manufacturer metadata.manufacturer str Direct Yes
    housing_type metadata.housing_type str Direct Yes
    comment metadata.comment str Direct No
    datasheet_hyperlink metadata.datasheet_hyperlink str Direct No
    datasheet_date metadata.datasheet_date datetime Parse YYYY-MM format No
    datasheet_version metadata.datasheet_version str Direct No

    2.3 Electrical Ratings Fields¶

    Source Field TDB Field Unit Conversion
    v_abs_max electrical_ratings.v_abs_max V Direct
    i_abs_max electrical_ratings.i_abs_max A Direct
    i_cont electrical_ratings.i_cont A Direct
    (inferred) electrical_ratings.t_j_max °C From switch.t_j_max or default

    2.4 Thermal Properties Fields¶

    Source Field TDB Field Unit Conversion
    housing_area thermal_properties.housing_area m² Direct
    cooling_area thermal_properties.cooling_area m² Direct
    r_th_cs thermal_properties.r_th_cs K/W Direct
    r_th_switch_cs thermal_properties.r_th_switch_cs K/W Direct
    r_th_diode_cs thermal_properties.r_th_diode_cs K/W Direct
    t_c_max thermal_properties.t_c_max °C Direct

    2.5 Switch/Diode Object Mappings¶

    Field Name Normalizations¶

    Source Name TDB Name Reason
    channel channel_data Clarify it's a collection
    e_on e_on_data Clarify it's loss data
    e_off e_off_data Clarify it's loss data
    charge_curve gate_charge_curves More descriptive
    r_channel_th r_channel_temp Consistency
    linearized_switch linearized_model Component-agnostic
    linearized_diode linearized_model Component-agnostic

    Channel Data Structure¶

    {
  "t_j": 25,                          // Junction temperature in °C
  "graph_v_i": [                      // 2D array [voltages, currents]
    [0.0, 0.5, 1.0, ...],            // Voltages in V
    [0.0, 10.0, 20.0, ...]           // Currents in A
  ],
  "v_g": 5.0                         // Gate voltage in V (switch only)
}

    TDB Conversion: 

    channel_data.append(ChannelCharacteristics(
    t_j=source['t_j'],
    graph_v_i=np.array(source['graph_v_i']),
    v_g=source.get('v_g')
))

    2.6 Extra Fields in File Exchange¶

    File Exchange includes fields not in TDB core:

    {
  "technology": null,
  "template_version": null,
  "template_date": null,
  "creation_date": null,
  "last_modified": null,
  "r_g_int": 3.8,
  "r_g_on_recommended": null,
  "r_g_off_recommended": null,
  "c_oss_fix": 6.8e-11,
  "c_iss_fix": 4.975e-09,
  "c_rss_fix": null,
  "graph_v_ecoss": [...]
}

    Handling Strategy: 1. Store in switch.metadata dict (Switch has metadata: Dict[str, Any]) 2. Example: switch.metadata['r_g_int'] = 3.8 3. This preserves information without polluting core schema

    2.7 Conversion Pseudocode¶

    def convert_file_exchange_to_tdb(source_json: dict) -> Transistor:
    # Step 1: Create metadata
    metadata = TransistorMetadata(
        name=source_json['name'],
        type=source_json['type'],
        author=source_json['author'],
        manufacturer=source_json['manufacturer'],
        housing_type=source_json['housing_type'],
        comment=source_json.get('comment'),
        datasheet_hyperlink=source_json.get('datasheet_hyperlink'),
        datasheet_date=parse_date(source_json.get('datasheet_date')),
        datasheet_version=source_json.get('datasheet_version')
    )

    # Step 2: Create electrical ratings
    electrical = ElectricalRatings(
        v_abs_max=source_json['v_abs_max'],
        i_abs_max=source_json['i_abs_max'],
        i_cont=source_json['i_cont'],
        t_j_max=source_json['switch'].get('t_j_max', 175.0)
    )

    # Step 3: Create thermal properties
    thermal = ThermalProperties(
        housing_area=source_json['housing_area'],
        cooling_area=source_json['cooling_area'],
        r_th_cs=source_json.get('r_th_cs'),
        r_th_switch_cs=source_json.get('r_th_switch_cs'),
        r_th_diode_cs=source_json.get('r_th_diode_cs'),
        t_c_max=source_json.get('t_c_max')
    )

    # Step 4: Create transistor
    transistor = Transistor(metadata, electrical, thermal)

    # Step 5: Convert switch
    convert_switch_object(source_json['switch'], transistor.switch)

    # Step 6: Convert diode
    convert_diode_object(source_json['diode'], transistor.diode)

    # Step 7: Convert capacitances
    for cap_data in source_json.get('c_oss', []):
        transistor.c_oss.append(VoltageDependentCapacitance(
            t_j=cap_data['t_j'],
            graph_v_c=np.array(cap_data['graph_v_c'])
        ))

    # Similar for c_iss, c_rss

    return transistor

    3. SC Archive Format Conversion¶

    3.1 Format Characteristics¶

    • Structure: Graph format with calibration and data points
    • Challenge: Individual curve files without metadata context
    • Integration: Requires metadata file pairing
    • Unit Inference: May need to determine units from context

    3.2 SC Graph Structure¶

    {
  "version": [4, 2],
  "axesColl": [
    {
      "name": "XY",
      "type": "XYAxes",
      "isLogX": false,
      "isLogY": false,
      "calibrationPoints": [...]
    }
  ],
  "datasetColl": [
    {
      "name": "id25",
      "axesName": "XY",
      "data": [
        {"x": 276.5, "y": 755.8, "value": [2.567, 0.0798]},
        {"x": 287.5, "y": 757.3, "value": [2.713, 0.0005]},
        ...
      ]
    }
  ]
}

    3.3 Conversion Process¶

    Step 1: Extract Data Points 

    def extract_sc_curve(sc_json: dict) -> tuple[list, list]:
    """Extract x,y coordinates from SC graph format."""
    dataset = sc_json['datasetColl'][0]
    points = dataset['data']

    x_values = [pt['x'] for pt in points]
    y_values = [pt['y'] for pt in points]

    return x_values, y_values

    Step 2: Apply Calibration 

    def apply_calibration(x_raw: list, y_raw: list,
                      calibration_points: list) -> tuple[list, list]:
    """Convert pixel coordinates to physical coordinates."""
    # Calibration points: {px, py, dx, dy}
    # px/py = pixel coordinates
    # dx/dy = physical coordinates

    # Build linear transformation: physical = m * pixel + b
    # Using two calibration points
    cp1, cp2 = calibration_points[1], calibration_points[3]

    # X transformation
    m_x = (cp2['dx'] - cp1['dx']) / (cp2['px'] - cp1['px'])
    b_x = cp1['dx'] - m_x * cp1['px']

    # Y transformation
    m_y = (cp2['dy'] - cp1['dy']) / (cp2['py'] - cp1['py'])
    b_y = cp1['dy'] - m_y * cp1['py']

    x_physical = [m_x * px + b_x for px in x_raw]
    y_physical = [m_y * py + b_y for py in y_raw]

    return x_physical, y_physical

    Step 3: Identify Curve Type

    Analyze filename or context: - Filename containing "idvgs" → V-I characteristic (channel_data) - Filename containing "eon" → Turn-on loss (e_on_data) - Filename containing "eoff" → Turn-off loss (e_off_data) - Filename containing "errt" → Reverse recovery (diode e_rr_data)

    Step 4: Convert to TDB 

    def sc_curve_to_channel_data(x: list, y: list, t_j: float,
                              v_g: float = None) -> ChannelCharacteristics:
    """Convert SC curve to TDB ChannelCharacteristics."""
    return ChannelCharacteristics(
        t_j=t_j,
        graph_v_i=np.array([x, y]),
        v_g=v_g
    )

    4. Unit Handling and Validation¶

    4.1 Standard Units¶

    Quantity Unit Symbol Typical Range
    Temperature Celsius °C -40 to +200
    Voltage Volt V 0 to 1700
    Current Ampere A 0 to 1000
    Resistance Ohm Ω 0.001 to 100
    Capacitance Farad F 1e-12 to 1e-6
    Energy Joule J 1e-6 to 1e-1
    Thermal R K/W K/W 0.1 to 10

    4.2 Unit Conversions¶

    If source uses different units:

    UNIT_CONVERSIONS = {
    # Temperature
    ('F', 'C'): lambda x: (x - 32) * 5/9,
    ('K', 'C'): lambda x: x - 273.15,

    # Voltage
    ('mV', 'V'): lambda x: x * 0.001,
    ('kV', 'V'): lambda x: x * 1000,

    # Current
    ('mA', 'A'): lambda x: x * 0.001,
    ('kA', 'A'): lambda x: x * 1000,

    # Capacitance
    ('pF', 'F'): lambda x: x * 1e-12,
    ('nF', 'F'): lambda x: x * 1e-9,
    ('μF', 'F'): lambda x: x * 1e-6,
    ('mF', 'F'): lambda x: x * 1e-3,

    # Resistance
    ('mΩ', 'Ω'): lambda x: x * 0.001,
    ('μΩ', 'Ω'): lambda x: x * 1e-6,
}

    4.3 Data Validation Rules¶

    Always validate after conversion:

    def validate_transistor(tr: Transistor) -> list[str]:
    """Validate transistor data. Returns list of errors."""
    errors = []

    # Electrical ratings
    if tr.electrical_ratings.v_abs_max <= 0:
        errors.append(f"Invalid v_abs_max: {tr.electrical_ratings.v_abs_max}")
    if tr.electrical_ratings.i_abs_max <= 0:
        errors.append(f"Invalid i_abs_max: {tr.electrical_ratings.i_abs_max}")
    if tr.electrical_ratings.i_cont > tr.electrical_ratings.i_abs_max:
        errors.append(f"i_cont > i_abs_max: {tr.electrical_ratings.i_cont} > {tr.electrical_ratings.i_abs_max}")

    # Channel data
    for ch_data in tr.switch.channel_data:
        v_i = ch_data.graph_v_i
        if v_i.shape[0] != 2:
            errors.append(f"Invalid V-I array shape: {v_i.shape}")
        if v_i.shape[1] == 0:
            errors.append("Empty V-I array")
        if not np.all(np.diff(v_i[1]) >= 0):
            errors.append("V-I currents not monotonically increasing")

    return errors

    6. Code Examples¶

    Example 1: Complete File Exchange Conversion¶

    from transistordatabase.core.models import Transistor, TransistorMetadata, ElectricalRatings, ThermalProperties
import json
import numpy as np
from datetime import datetime

def convert_file_exchange(filepath: str) -> Transistor:
    """Convert File Exchange JSON to TDB Transistor."""
    with open(filepath) as f:
        data = json.load(f)

    # Extract metadata
    metadata = TransistorMetadata(
        name=data['name'],
        type=data['type'],
        author=data['author'],
        manufacturer=data['manufacturer'],
        housing_type=data['housing_type'],
        comment=data.get('comment'),
        datasheet_hyperlink=data.get('datasheet_hyperlink'),
        datasheet_date=_parse_date(data.get('datasheet_date')),
        datasheet_version=data.get('datasheet_version')
    )

    # Extract electrical ratings
    electrical = ElectricalRatings(
        v_abs_max=float(data['v_abs_max']),
        i_abs_max=float(data['i_abs_max']),
        i_cont=float(data['i_cont']),
        t_j_max=float(data['switch'].get('t_j_max', 175.0))
    )

    # Extract thermal properties
    thermal = ThermalProperties(
        housing_area=float(data['housing_area']),
        cooling_area=float(data['cooling_area']),
        r_th_cs=float(data.get('r_th_cs', 0)) or None,
        r_th_switch_cs=float(data.get('r_th_switch_cs', 0)) or None,
        r_th_diode_cs=float(data.get('r_th_diode_cs', 0)) or None,
        t_c_max=data.get('t_c_max')
    )

    # Create transistor
    transistor = Transistor(metadata, electrical, thermal)

    # Convert switch
    _convert_switch(data['switch'], transistor.switch)

    # Convert diode
    _convert_diode(data['diode'], transistor.diode)

    # Convert capacitances
    for cap in data.get('c_oss', []):
        transistor.c_oss.append(_create_voltage_dependent_capacitance(cap))

    for cap in data.get('c_iss', []):
        transistor.c_iss.append(_create_voltage_dependent_capacitance(cap))

    for cap in data.get('c_rss', []):
        transistor.c_rss.append(_create_voltage_dependent_capacitance(cap))

    # Convert effective capacitances
    if data.get('c_oss_er'):
        transistor.c_oss_er = _create_effective_capacitance(data['c_oss_er'])

    if data.get('c_oss_tr'):
        transistor.c_oss_tr = _create_effective_capacitance(data['c_oss_tr'])

    return transistor

def _parse_date(date_str: str) -> datetime:
    """Parse date string in YYYY-MM format."""
    if not date_str:
        return None
    try:
        # Try YYYY-MM format
        return datetime.strptime(date_str, '%Y-%m')
    except ValueError:
        # Try ISO format
        return datetime.fromisoformat(date_str)

    Example 2: Validation After Conversion¶

    def validate_and_report(transistor: Transistor) -> dict:
    """Validate transistor and return comprehensive report."""
    report = {
        'name': transistor.metadata.name,
        'valid': True,
        'errors': [],
        'warnings': [],
        'info': {
            'v_abs_max': transistor.electrical_ratings.v_abs_max,
            'i_abs_max': transistor.electrical_ratings.i_abs_max,
            'channels': len(transistor.switch.channel_data),
            'e_on_entries': len(transistor.switch.e_on_data),
            'e_off_entries': len(transistor.switch.e_off_data),
            'c_oss_curves': len(transistor.c_oss),
        }
    }

    # Check electrical ratings
    if transistor.electrical_ratings.v_abs_max <= 0:
        report['errors'].append('v_abs_max must be > 0')
    if transistor.electrical_ratings.i_cont > transistor.electrical_ratings.i_abs_max:
        report['errors'].append('i_cont cannot exceed i_abs_max')

    # Check channel data integrity
    for i, ch in enumerate(transistor.switch.channel_data):
        v_i = ch.graph_v_i
        if v_i.shape[1] == 0:
            report['errors'].append(f'Channel {i}: empty curve')
        if v_i.shape[0] != 2:
            report['errors'].append(f'Channel {i}: invalid shape {v_i.shape}')

    # Check for minimum required data
    if len(transistor.switch.channel_data) == 0:
        report['warnings'].append('No switch channel data')

    report['valid'] = len(report['errors']) == 0
    return report

    7. Performance Considerations¶

    • Memory: File Exchange files (~250KB) load into ~1MB in-memory objects
    • Arrays: Store graphs as numpy arrays for efficient access
    • Batch Processing: Use generators for large imports
    • Database: Repository layer handles persistence
